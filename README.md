# MonitorSync

Control your monitor's brightness and speaker volume from the Windows 11 tray.

- **Brightness** targets the screen under your mouse cursor.
- **Volume** stays in sync with Windows for the selected monitor speakers.

| --- | --- |
| <img src="docs/images/tray-light.png" alt="MonitorSync tray menu in light theme" width="280"> | <img src="docs/images/tray-dark.png" alt="MonitorSync tray menu in dark theme" width="280"> |

[Download](https://github.com/nkatchik/win-monitor-sync/releases) the preview ZIP, extract it, and run `MonitorSync.exe`. Enable **DDC/CI** in your monitor's menu. Preview builds are unsigned.

Click the tray icon for sliders, individual control toggles, and **Start with Windows**. Use brightness keys where supported, or **Ctrl+Alt+Page Up / Page Down**.
